# Drip & Drop Coffee — Specialty Coffee & Kitchen

> Premium website & digital ordering proposal for **Drip And Drop Coffee**, JP Nagar Phase 5, Bengaluru.

## ☕ About The Project

This website is designed with boutique editorial aesthetics inspired by Onyx Coffee Lab, % Arabica, and La Cabra. It offers an authentic representation of Drip & Drop's craft coffee program, all-day kitchen (Korean buns, bakes, gourmet burgers), and space in Bengaluru.

## 🛠 Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Custom editorial palette & typography)
- **Icons**: Lucide React
- **Fonts**: Plus Jakarta Sans & Newsreader Serif

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
